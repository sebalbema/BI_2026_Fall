# Visualización interactiva de pases

Aplicación desarrollada en Python utilizando Streamlit para analizar y visualizar pases de un partido del Mundial de Qatar 2022.

Los datos utilizados provienen de StatsBomb Open Data.

## Tecnologías utilizadas

- Python
- Streamlit
- Pandas
- Seaborn
- Matplotlib
- StatsBombPy
- MPLSoccer

## Funcionamiento

La aplicación obtiene los eventos de un partido del Mundial de Qatar 2022 y filtra únicamente aquellos correspondientes a pases.

Las coordenadas iniciales y finales de cada pase son utilizadas para representarlos sobre una cancha de fútbol.

El usuario puede seleccionar de forma interactiva el minuto del partido mediante un slider.

## Fuente de datos

StatsBomb Open Data.
